## win.16：已确认接口的三秒握手回落

已确认有效输出后，接口短暂降到低功率、<=0.2W 或 0W 时，先将这一段作为待确认的握手回落。若从首个回落样本起三秒内观察到有效恢复，回填期间实际采到的数值，曲线连续体现真实下降与回升，不用插值或旧值填平。三秒整包含在宽限范围内；超过三秒未恢复，则保持空段，避免将拔线后的零功率或线材脉冲画成持续负载。

为避免线材 0.5W 脉冲被误当作恢复，高功率会话需要恢复到至少 0.7W；已经确认的低负载会话可以恢复到此前功率的 80% 且 >0.2W。没有确认过的接口不享有握手宽限，仍需原有持续超过五秒或功率攀升规则。各接口独立判断，160W 与 250W 均适用短暂握手回落的处理。

被接受的 0.1W、0W 点带有明确有效标记，App 与组件均绘制这些真实点；普通待机、未确认短脉冲和长期零功率仍不画底线。已经确认的握手点会保留原始数值与有效性，不会因之前的高功率点移出五分钟窗口而改成 0W 或提前消失。

此规则针对曲线展示；3D 连线、原始数字和真实能耗保持现有处理。App 五分钟、组件一分钟，原有权限与布局不变。

## 当前样本确认与 3D 连线

160W 原始接口功率 >0.2W 且 <0.7W 时先观察，连续采样持续超过五秒才确认，五秒整仍不确认。若功率攀升到 >=0.7W，立即确认，并回填紧接在前的低功率起步段。回到 <=0.2W 或相邻样本间隔超过 2.5 秒会中断观察，不累积孤立脉冲。确认过的历史点保留确认状态，直到滚出五分钟窗口。

160W 的 3D 连线读取后台对“当前接口样本”的确认结果：未确认短脉冲、待机、零功率与关闭端口均不显示连线，不会因为仍识别到线材或历史中存在旧峰值而保留连线。确认的持续低负载或 >=0.7W 的即时有效输出才显示。连线变化保留短动画；数字读数、屏幕显示与能耗仍为原始测量，未被过滤或置零。250W 沿用原有接入状态处理。

这是基于功率与持续时间的显示规则，不能百分之百判断物理设备接入。超过五秒的线材异常或更高功率异常也可能通过。真实线材和设备仍需用户验证。

## 实时总览布局

两型号共用紧凑布局：总功率上方间距缩小，3D 区域高度适当收紧，右侧曲线略微下移并增加绘图区高度；统计区域靠近卡片底部，三项等宽居中，数值字体从 16px 提高至 20px，标签字体提高至 11px。保留合理间距，避免大块无意义留白。

## 曲线与记录

后台按设备身份持续缓存，不依赖页面、选中型号、窗口显示或组件开关。App 为最近五分钟、组件为最近一分钟，两处纵轴共用五分钟有效峰值加 15% 余量并向上取整，横轴时长各自固定。

没有已确认有效接口输出时，正式曲线记录为空；各接口 <=0.2W 或只有未确认短脉冲不会启动正式记录。候选样本只暂存用于后续确认和回填。当前归零不会抹掉仍在窗口中的有效历史。曲线缓存只保留最近五分钟，过期移除；累计能耗的磁盘历史单独保留。普通 0～0.2W 和被过滤的脉冲区间不画底线，已确认的短暂握手回落按上文规则保留真实低点。

功率数值刷新仍可选默认或 1～10 秒，不影响原始采集、确认计时和记录。App 的端口状态保留原始功率、电压、电流。

## 连接与管理

每次启动对每型号最近保存设备仅尝试一次，失败后手动连接。160W 需要电脑蓝牙开启并退出占用连接的手机 Anker App，250W 需要有效账号令牌。仍同时支持最多一台 160W 和一台 250W，可保存多台同型号设备供切换。

保存设备可重命名和移除，显示地址、读取到的序列号/硬件 MAC；名称同步总览和组件，重连不覆盖。移除只忘记本地保存，不关闭端口或删除历史。同机按验证身份去重，不按同名合并两台真实设备。

160W 扫描依据 A2687/B405 或 ASHE 等型号证据，并在握手后复核 ASHE/已验证的 ASHD 序列号。AFYD 等其他产品会拒绝连接并从充电器保存列表排除；首次清理前保留 settings-before-model-filter.json 设置备份。

## 权限与组件

未连接时整个设备控制页禁用。“允许端口开关、倒计时与定时”控制端口开关、倒计时入口及倒计时/每周定时全部字段；“允许实验性控制”控制其余设备设置，包括亮度、屏幕、模式、分配、图片和主题。前后端独立检查两组权限，禁用控件不显示忙碌光标。

组件开关、锁定、置顶、位置重置都在 App 应用设置，可拖动并记住位置，无关闭按钮与右键菜单。隐藏主窗口后继续显示，托盘退出后关闭。组件总功率仍为 160W 珊瑚红、250W 黄绿色，A2 为橙色。
