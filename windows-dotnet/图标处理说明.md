# 小熊图标

使用 imagegen 技能和内置 image_gen 编辑工具，从用户提供的小熊圆形图片提取图标，圆外透明。产物位于 UI/assets/AppIcon.png，Windows 多分辨率图标为 UI/assets/AppIcon.ico（16、24、32、48、64、128、256 像素）。图标已用于窗口、托盘、应用界面和交付快捷方式。

提交给内置工具的提示词：

> Use case: background-extraction. Edit target: attached screenshot. Produce a square Windows app icon asset by extracting ONLY the large central circular picture of the cute beige teddy bear holding a white enamel mug. Preserve the original bear, mug, pose, expression, circular photo background and framing as faithfully as possible. Crop to the exact existing circle, filling the square canvas with that circle. The four corners outside the circle must be fully transparent. Remove ALL outer black screenshot regions and all phone UI: no orange dot, no X, no like button, no arrow, no text, no added border or shadow. Do not redesign the bear. Save as transparent PNG suitable for 256px app icons.

win.17 起，仅对 Windows ICO 的源取样区域收紧透明边距（1254×1254 原图中 x=46、y=49、1160×1160 区域），使圆形图案尽量占满图标画布。仍保留全部七档分辨率与透明通道；应用界面使用的 PNG 原图未改动。转换脚本见 Installer/convert-icon.ps1。
