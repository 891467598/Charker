## 0.5.1-win.31

- 桌面组件从最后一次有效输出起，满 2 分钟收成一行，满 5 分钟隐藏。恢复有效输出时立即展开。
- Windows 解锁或唤醒后恢复桌面组件，并对先前连接且当前失联的蓝牙充电器进行有限重试。160W 直接打开失败时会补扫保存的地址。
- 支持酷态科 10 Ultra（AD1204U）的蓝牙监测、端口读数与 3D 模型。支持从米家导入配对信息。
- 250W 云端连接失败时以 2 秒为间隔尝试恢复，重试窗口到第 20 秒截止。支持保存、重命名和移除云端设备。
- 华为 SCP 端口按实测电压与电流计算功率。

# 0.5.1-win.19

仅调整 250W 已建立连接后的意外断线恢复：在断线后的第 2、4、6、8、10 秒依次尝试，最多五次，每次连接限时最多两秒。第五次最晚第十二秒结束。成功立即停止本轮，失败后手动连接；手动断开、退出账号、切换云端设备及退出程序均取消剩余尝试。首次启动失败仍不进入此重连轮次。160W、界面、组件、采样和历史规则不变。

自动恢复复用已确认的设备身份，并重新请求云端连接信息。取消令牌贯穿 HTTP、TLS 及 MQTT 握手，防止旧请求拖过下一次时段；上一尝试清理结束后才开始下一次，不并发连接。

# 0.5.1-win.18

应用设置新增“开机自启动（后台运行）”，勾选立即保存到当前用户的 Windows 登录启动项；取消即移除。自启动使用 --background，主界面不显示、不占任务栏，保留托盘图标，桌面组件按原设置显示；从托盘点击可手动打开。手动启动仍正常显示主界面。

250W 已成功连接后发生意外断线（含网卡地址变化）时，取消旧会话并在五秒后仅尝试重连一次，失败不再尝试。接收、轮询和网络事件重复报告同一掉线不会叠加任务；重连成功后，日后再次独立掉线可再尝试一次。手动断开、退出账号、切换设备、退出程序取消待重连；启动首次失败仍不重复尝试。160W 行为、曲线、记录和组件样式保持不变。

# 0.5.1-win.16

已确认有效负载后，三秒内完成有效恢复的短暂功率回落会回填真实采样点，保留低于 0.2W 和 0W 的下降/回升轨迹。超过三秒未恢复、没有确认过的线材脉冲仍留空，不恢复长期零功率基准线。各接口独立处理，适用于两个型号。

App 和组件共用有效点标记，可以区分“真实握手 0W”与“已过滤的无效点”，避免绘图时因数值低而再次断线。所有数值都是实际采样，不插值、不修改原始端口读数或能耗。五分钟缓存、一分钟组件、权限与界面布局保留。
