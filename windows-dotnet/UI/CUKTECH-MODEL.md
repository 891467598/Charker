# 10 Ultra外观模型

这是原创参数几何，未使用第三方网格或产品照片贴图。用户提供四张外观/接口参考图；尺寸参考ChargerLAB原始测量：
https://www.chargerlab.com/teardown-of-cuktech-10-gan-charger-ultra-ad1204u/

名义尺寸33.13×66.89×75.59毫米。坐标x为厚度，y为屏幕长边方向，z为接口长边方向；屏幕在+z，输出在-y，输入插脚在+y。C1/C2/C3/A孔中心z依次为23.8/12.8/1.8/-10.2毫米。接口间距、饰件与细节依据照片比例重建，不是制造尺寸。折叠插脚用收起状态呈现。

输出盖板带真实开孔，插头根节点取自孔节点；局部+z沿孔的外法线。屏幕在玻璃前约0.015毫米，随本体一起旋转。银色侧壳采用倒角挤出，显示屏内容与标签由程序绘制。线缆从正确插口出发，USB-C与USB-A保留不同金属头、外壳和线径。材料、标签、几何均为本项目代码创建；参考照片不随软件分发。

UI/test-driver.js在隔离测试中核对孔位、法线、盖板通透、屏幕贴合、银色侧壳可见性，以及front/ports/right/back/oblique五角度和C2/A/idle状态。截图使用明确标识的模拟功率，不代表实机采样。
